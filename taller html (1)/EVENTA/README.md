# EVENTA - Plataforma de eventos

Proyecto Integrador UCEVA - Maquetación Web Responsiva.

## Descripción
Home Page principal de EVENTA desarrollada con enfoque Mobile-First y alineada con el diseño planteado en Figma.

## Tecnologías
- HTML5 semántico
- CSS3
- CSS Grid y Flexbox
- Media Queries con `min-width`

## Breakpoints
- Base: 375px, una columna
- Tablet: 768px, dos columnas
- Desktop: 1024px, cuatro columnas y navegación con Inicio centrado

## Entregables
- `index.html`
- `css/styles.css`
- `README.md`

## Ejecución
Abrir `index.html` en un navegador web. Las imágenes utilizadas provienen de Unsplash mediante URLs externas.
